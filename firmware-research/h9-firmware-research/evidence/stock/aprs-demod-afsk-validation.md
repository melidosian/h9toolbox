# APRS demodulator synthetic AFSK validation

`replacement-source/tests/test_external_afsk.c` validates the ported receive chain with a signal generated independently of its transmit code. It uses fixed AX.25 UI bytes for `APRS > KD9CRQ`, information `>TEST`, and independently calculated FCS bytes `FA 9B`. The test serializes each byte least-significant bit first, inserts a zero after five consecutive one bits, encodes zero bits as AFSK tone changes, and synthesizes continuous-phase 1,200/2,200 Hz sine samples. Fifty opening HDLC flags provide acquisition time. Each sample is converted to a synthetic 10-bit ADC reading and fed through `h9_aprs_controller_adc_tick`. The controller's receive poll sends a `0x00` serial frame; the main firmware frame receiver and AX.25 decoder must accept it as exactly one packet with the original 21 payload bytes and decoded addresses and information.

The test passes at 9,600 samples/s and at `24,000,000 / (11+1) / (209+1)`, approximately 9,524 samples/s. The second rate follows the recovered timer prescaler and period in stock APRS v1.0.15, but the actual timer-to-ADC trigger and input scaling remain unmeasured. Pure synthetic sine input does not prove reception through the TD-H9 RF front end, ADC, physical UART, or live APRS channel. The older TX-to-RX loopback test checks the replacement waveform encoder; this test exercises a separately generated waveform through the replacement APRS and main receive sources.

The same test withholds main-loop polling for 100 HDLC flags to force overflow of the 64-byte ADC ISR receive queue. It verifies that only the main-loop consumer clears queued bytes after observing the overflow generation, then sends a fresh preamble and packet. A 100-flag reacquisition preamble recovers the packet at both rates; 50 flags after overflow did not reliably reacquire at the timer-derived rate in this synthetic fixture. This test establishes source recovery under its exact waveform and scheduling, not a physical packet-loss bound.
