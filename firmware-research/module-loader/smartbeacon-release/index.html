SmartBeacon bench firmware

The development build adds automatic Smart and Timed APRS beacons, APRS Mute, and the grouped Toolbox menu with keypad shortcuts. It runs on the TD-H9 and uses loader API 5. The radio may report v0.1.4.

Download the matched files

  • Main firmware (.fw)
  • SmartBeacon scheduler image (.bin)
  • API 5 app bundle (.bin)
  • SHA-256 checksums

The firmware and scheduler must match for automatic beaconing to run. Use the desktop USB flasher for these two files and the App Manager for the matching apps.

Install on a bench radio

  1. Before updating, disarm the Toolbox beacon schedule if one is set. In the App Manager, read the radio and save its app bundle. Keep that file and your firmware backups.
  2. Follow the desktop USB flasher setup to identify your radio in the BR23 USB loader. You’ll need the exact stock Type-C v1.0.38 package for the tool’s --stock-base check.
  3. Run the desktop flasher’s backup command with the downloaded main firmware, --stock-base, and a new --backup filename. Keep the resulting main-flash backup and its adjacent JSON manifest. Re-enter the USB loader and verify the device path again.
  4. Use write-far with the downloaded scheduler image and --address 0xFA000. Use a separate new --backup filename. The flasher saves and verifies the affected two sectors. Keep this backup for rollback. Re-enter the USB loader and verify the device path again before the next command.
  5. Run flash with the downloaded main firmware, the same --stock-base, and the main-flash backup from step 3. Wait for readback verification, then boot the radio normally with a dummy load or attenuated test setup connected.
  6. In the SmartBeacon App Manager, connect, open Advanced, select Load whole bundle, and choose the API 5 app bundle. Write to radio replaces the installed apps with the contents of that bundle. Keep your previous app backup if you want to restore it later.

Before arming a schedule, check the APRS modem and follow the SmartBeacon bench checks. An armed schedule can resume after reboot.

Return to the previous build

Re-enter the BR23 USB loader. Use the desktop flasher’s restore command with the bench .fw, the same --stock-base, and the main backup from step 3. Re-enter the loader and verify the device path again. Then use write-far at 0xFA000 with the scheduler backup from step 4 and a fresh backup filename. Wait for both verifications before rebooting. Use the App Manager to restore your saved app bundle if you replaced it.

If you can’t reach the desktop loader, see the TD-H9 recovery guide.
