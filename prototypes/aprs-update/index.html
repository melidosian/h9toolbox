APRS modem update

Update the packet radio modem in your USB-C TD-H9. If an update was already loaded onto your radio, you can finish from the keypad. For a USB update, use Chrome or Edge on a Windows computer.

Update from the radio Update with a USB cable

Update from the radio

Use this if your H9 already has a staged APRS update, meaning the update file is stored on the radio. You only need the radio and a charged battery.

  1. Unplug USB and turn the radio off. Hold the side PTT (talk) button and the keypad 7 together while turning the radio on. Let go when the screen says APRS Update.
  2. Press Menu once and let go. If you see APRS STAGE READY, the radio found a valid update. To leave without writing, press Back. If the screen stays on APRS Update, press Back to return to normal operation and follow the USB steps.
  3. At APRS STAGE READY, press Menu again to write the update. Keep the radio on until you see APRS BOOT VERIFIED with the version underneath.
  4. Turn the radio off and back on normally. Open APRS Info and check that it shows the same version. The marked packet firmware shows V1.0.15X. Earlier staged builds show V1.0.15.

If the radio reports a missing acknowledgment or cannot verify the modem boot, use the recovery steps below.

USB step 1. Save the recovery file

Use desktop Chrome or Edge on Windows. Charge the radio and have a USB-C cable that carries data. Mac browsers can download the recovery file. For writing on macOS, use the staged update on the radio if your H9 has one.

  1. Click Load firmware files. Wait for the page to verify the packet firmware and the original APRS firmware.
  2. Click Save stock recovery file. Keep APRS-1.0.15.bin in your Downloads folder or somewhere easy to find.

USB step 2. Connect the radio

Disconnected
  1. Turn the radio off and connect the USB-C cable between the radio and computer.
  2. Hold the side PTT button and the keypad 7 together. Turn the radio on while holding both. Release them when the radio shows APRS Update.
  3. Click Select USB port. Select the radio in the browser’s list and click Connect. It may be listed as a USB serial device.
Nothing in the USB list?

Close other radio programs and flasher tabs. Try a cable you have used for file transfers, plug it directly into the computer, and repeat step 2.

USB step 3. Write the update

Choose the packet receive fix for KISS packet connections, or choose the original APRS firmware to recover a modem. Tick the box below and click Write APRS firmware. Leave the radio on and the USB cable connected until the page says the transfer finished.

USB step 4. Check that APRS starts

  1. When the page says the transfer finished, turn the radio off and unplug the cable. Turn the radio back on normally, with no keys held.
  2. On the radio, open APRS Info. The firmware files offered by this USB tool both show V1.0.15. If you installed the packet fix, try receiving a packet.
If the update stops or APRS Info stays on Querying…
  1. Save the transfer log if you updated from this page. Turn the radio off.
  2. On Windows, connect USB and use PTT + 7 to return to APRS Update. Choose Original firmware in USB step 3 and write it. If the browser cannot complete the write, use the saved stock file with the Windows recovery tool.
  3. Turn the radio off, unplug USB, and turn it back on. Check for V1.0.15 in APRS Info.
