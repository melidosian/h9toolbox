APRS modem update

Install the packet receive fix or restore stock APRS 1.0.15 on a TD-H9 Type-C. This page writes the separate APRS modem.

Keep a stock recovery file

The browser updater has been tested with a simulated radio. The Windows command-line updater is the hardware-verified USB-C path and can restore the stock image. Earlier Mac transfers received acknowledgments while the radio still showed Querying… after reboot.

Prepare firmware

Load the packet fix and stock recovery image. Both files are checked against their exact SHA-256.

Select the radio

Disconnected
  1. Turn the radio off and attach a data-capable USB-C cable.
  2. Hold PTT + 7 while powering on. The radio must show APRS Update.
  3. Click Select USB port and choose the TD-H9 serial port.

Write APRS firmware

0 / 17,304 bytes acknowledged
Ready to prepare firmware.

Keep USB connected during the write. After a completed transfer, power-cycle normally, check APRS Info → V1.0.15, and test packet reception.
