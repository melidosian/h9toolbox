TD-H9 remote control discovery

This local experiment checks how the TD-H9 stores A/B VFO, memory-channel selection, and RX volume. Listening and snapshot buttons only read. The labeled select/set and volume test buttons make guarded configuration writes. No button sends PTT, APRS, or erase commands.

Keep APRS Connect disconnected and its beaconing off. Leave CH-A off a repeater while testing. Use the radio's Bluetooth programming mode; disconnect other radio apps first.

1. Connect

Disconnected.

2. Watch manual controls

Start listening, manually change A/B or RX volume on the radio, then stop. Any BLE notifications appear in the log. This stage sends no commands.

3. Compare saved radio state

With A selected, capture A1. Then switch to B on the radio and capture B. Switch back to A and capture A2. Each capture enters and exits the known read-only programming protocol. If the radio will not let you change VFO while connected, disconnect between steps.

No snapshots yet.

4. Try selecting A or B

The A/B/A result identified configuration byte 0x3004 (A=00, B=01). This unverified test changes only that byte in its 32-byte radio block. It checks radio identity, the saved baseline, ACK, and readback. It does not send PTT or APRS. The radio might apply this only after leaving programming mode or a restart.

First capture and download a fresh full backup. Keep CH-A off a repeater, and check the radio's display after each write.

No safety backup in this browser session.

5. Discover and set B's memory channel

Capture a safety backup to locate the APRS memory channel.

With B selected, click Read B before. Manually change B to a different stored memory channel on the radio, then click Read B after. The page requires that only the candidate B channel byte change before it unlocks the restore test. The final button sets B back to the APRS memory and selects VFO B. Keep the dummy load attached and do not press PTT.

No B channel comparison yet.

6. One-pass B + APRS selection

This uses one complete read to make and download a fresh backup, locates the unique APRS / 144.390 MHz memory, writes B's channel field if needed, and writes B as the selected VFO. It verifies each written 32-byte block by readback. No manual before/after snapshots are needed. Keep the dummy load attached and APRS Connect beaconing disabled.

Not run.

7. Discover RX volume control

Set the radio's receive volume to a low or midrange level and capture Low 1. Manually raise it and capture High. Return near the original level and capture Low 2; an exact return is not required. Keep the channel and other settings unchanged. Disconnect between captures if the radio will not let you adjust volume while connected.

No RX volume snapshots yet.

The page tolerates a different returned low level if all changes stay at one 0–30 byte. The one-step buttons unlock only if the high value is exactly one stored step above the returned low value. Each test makes a fresh full backup, checks the whole image against the returned-low snapshot, writes one byte, checks ACK, and reads the block back. A matching stored byte does not prove that live RX audio changed. Check the radio's actual received audio after each test.

If all snapshots match, the clone image has no volume candidate. A separate read-only check is to use Start listening above while moving the volume control, then inspect the BLE notification log.
